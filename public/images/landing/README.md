# Landing photos

Drop optimised photos here with these exact file names. Until a file exists, the landing page shows a plain warm panel in its place.

| File | Used for | Notes |
| --- | --- | --- |
| `food-idli.jpg` | Food section | Indian breakfast, for example idli and sambar. |
| `everyday.jpg` | Everyday section | A real everyday moment, not a clinical setting. |
| `community.jpg` | Identity section | Warm, human, consent-cleared. |

Requirements: licensed or self-taken, under 200 KB each, 4:3 or 1:1, with no identifiable people unless they have consented. Alt text is set in code.
